** Rosaline

[[file:rosaline.avif]]

Rosaline is a small, beginner-friendly graphics and GUI library for Go. It is designed for people who know a little Go and want to make a real graphical program without first learning a large framework.

View on [[https://github.com/SeraphinaDX/Rosaline][Github]]

** BritneyDOS
Open an alternate reality. What would DOS be like in 2026 if it was not abandoned by Microsoft?

BritneyDOS uses the Linux kernel. Pipewire for sound. A custom wifi stack. A package manager...

The shell also has a clone of Norton Commander built in.

Written in Go. Memory safe, multithreaded, easy to read code.

Visit on [[https://github.com/SeraphinaDX/BritneyDOS][Github]]

** Mail Tools

*** MailSalon

MailSalon is a Maildir-based terminal mail client written in Go using gotui v5. It deliberately leaves network transport to external programs. MailSalon reads and modifies local Maildirs, while tools such as mbsync, offlineimap, MailSalonSync, msmtp, or custom wrapper scripts handle receiving and sending.

Visit on [[https://github.com/SeraphinaDX/MailSalon][Github]]

[[file:mailsalon.avif]]

*** MailSalonSync

MailSalonSync is a small, Maildir-first replacement for the common OfflineIMAP workflow, written in Go. It can mirror configured folders from either IMAP or JMAP accounts, propagate deletions in both directions, handle multiple accounts and mailbox-to-directory mappings, and submit raw RFC 5322 messages with JMAP.

While it works, an interactive terminal gets a Charm Bubble Tea/Bubbles spinner with the current account, mailbox, operation, and running add/delete counts. For scripting, Emacs, mu4e, cron-style use, and other non-interactive callers, -plain disables the interactive UI and runs synchronously.

Visit on [[https://github.com/SeraphinaDX/MailSalonSync][Github]]
