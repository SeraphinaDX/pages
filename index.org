** Rosaline

[[file:rosaline.avif]]

Rosaline is a small, beginner-friendly graphics and GUI library for Go. It is designed for people who know a little Go and want to make a real graphical program without first learning a large framework.

View on [[https://github.com/SeraphinaDX/Rosaline][Github]]

** BritneyDOS
Open an alternate reality. What would DOS be like in 2026 if it was not abandoned by Microsoft?

BritneyDOS uses the Linux kernel. Pipewire for sound. A custom wifi stack. A package manager...

The shell also has a clone of Norton Commander built in.

Written in Go. Memory safe, multithreaded, easy to read code.

[[https://git.cerberusgames.ca/Starstreak/BritneyDOS][View on Git]]

[[file:cmdr.avif]]

** Copperline
The best IRC client that Britney has ever used.

Mouse support, memory safe, multithreaded and written in Go.

A clone of weechat, but this motherfucker has themes and TOML based configuration.

[[https://git.cerberusgames.ca/Starstreak/Copperline][View on Git]]
